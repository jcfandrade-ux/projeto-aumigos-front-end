# ONG Aumigos!

## Visão Geral  
Este projeto é um sistema web desenvolvido para fornecer presença digital profissional e funcional para ONGs, incluindo páginas institucionais, cadastro e divulgação de projetos sociais, área para voluntários e gerenciamento de informações da organização.

##  Aplicação de CSS3

Nesta etapa, foi realizado o desenvolvimento da interface visual com foco em CSS3, obedecendo os seguintes requisitos:

- Sistema de Design com variáveis CSS customizadas:  
  - Paleta com mais de 8 cores (primárias, secundárias e neutras)  
  - Tipografia hierárquica com 5 níveis de fonte  
  - Sistema escalonado de espaçamentos (8px, 16px, 24px, 32px, 48px, 64px)  

- Leiautes responsivos aplicados usando CSS Grid e Flexbox, inclusive grid customizado de 12 colunas  

- Apresentação responsiva com múltiplos breakpoints (numerados, em progressão) para adequação em vários dispositivos  

- Navegação sofisticada e responsiva com menu dropdown puro CSS, além do menu hambúrguer para mobile via checkbox hack CSS (sem JavaScript)  

- Componentes visuais acessíveis e estilizados:  
  - Sistema de cards responsivos  
  - Botões com estados hover, focus, active e disabled  
  - Formulários com validação visual via focos e estados CSS  
  - Componentes para alertas, toasts e modais usando apenas CSS3  
  - Badges e tags para categorização visual

## Tecnologias Utilizadas  

- HTML5 semântico e acessível  
- CSS3 avançado para layout responsivo e componentes visuais  
- Imagens otimizadas e multimídia incorporada

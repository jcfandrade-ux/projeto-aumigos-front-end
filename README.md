# Aumigos! - Plataforma Web da ONG

##  Sobre o Projeto

Plataforma web completa para a ONG Aumigos, dedicada a proteger e auxiliar animais abandonados. A plataforma oferece uma interface moderna e funcional para conectar a ONG à comunidade, facilitando o voluntariado, doações e participação em projetos sociais.

##  Sobre a ONG

Aumigos transforma vidas e salva animais desde 2015, promovendo adoção responsável, educação e engajamento comunitário.

### Impacto Social

-  Mais de 1.500 animais resgatados  
-  100 voluntários ativos  
-  300 adoções realizadas  
-  Crescimento constante no engajamento da comunidade  

##  Funcionalidades da Plataforma

###  Para Visitantes

- Conhecer a missão e visão da ONG  
- Explorar projetos sociais ativos  
- Contatar via formulário  

###  Para Voluntários

- Cadastro simples  
- Visualização de oportunidades de voluntariado   

##  Páginas do Site

- Página Inicial: Apresentação da ONG  
- Projetos: Portfólio, doações e detalhes das ações  
- Cadastro: Formulário para voluntários 

##  Destaques

- Design responsivo para celular, tablet e desktop  
- Acessibilidade para todos usuários  
- Validação de formulários em tempo real   

##  Como Usar

1. Abra `index.html` no seu navegador  
2. Navegue pelas páginas públicas  
3. Cadastre-se como voluntário 
4. Doe, participe e ajude a transformar vidas
